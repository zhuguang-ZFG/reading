# reading

这是一个基于 Obsidian 构建的个人阅读笔记库。

仓库里不只是单本书的摘录，而是按以下结构逐步沉淀：

- 书籍主笔记：每本书一篇完整读书笔记
- 行动清单：把感悟转成可执行提醒
- 概念卡片：把重要概念拆成可复用的原子笔记
- 主线总纲：把阅读沉淀成长期可导航的知识地图
- 跨书索引：把多本书按共同主题重新连接

## 推荐入口

如果你在 Obsidian 中打开这个仓库，建议按下面顺序进入：

1. `00_NAV/欢迎.md`
2. `00_NAV/全库总导航.md`
3. `00_NAV/库内目录说明.md`
4. `01_INDEX/认知线总纲.md`
5. `01_INDEX/技术线总纲.md`
6. `01_INDEX/管理线总纲.md`
7. `01_INDEX/历史线总纲.md`

## 使用方式

### 1. 看单本书

先读某本书的主笔记，再看它对应的“行动清单与金句摘录”。

### 2. 看某条主线

直接从总纲进入：

- `01_INDEX/认知线总纲.md`
- `01_INDEX/技术线总纲.md`
- `01_INDEX/管理线总纲.md`
- `01_INDEX/历史线总纲.md`

### 3. 看某个主题

直接从 `01_INDEX/跨书主题索引.md` 进入，比如：

- 注意力、心性与内在修炼
- 复杂问题与系统结构
- 成长、积累与长期主义
- 创造力、探索与优化
- 决策、杠杆与关键行动

### 4. 持续扩展

以后每读一本新书，都可以继续沿用这套结构：

- 新建一篇主笔记
- 新建一篇行动清单
- 把可复用内容并入已有概念卡片
- 必要时补新的母题卡片
- 同时把新内容接回对应主线总纲
