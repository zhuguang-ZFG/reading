# reading

这是一个基于 Obsidian 构建的个人读书与知识整理库。

它不只是存放“每本书的摘录”，而是把阅读逐步沉淀成四层结构：

- 主笔记：每本书一篇完整读书笔记
- 行动页：把感悟压成可执行的提醒与清单
- 概念卡：把重要概念拆成可复用的原子笔记
- 索引与总纲：把单本书连接成长期可导航的知识网络

## 推荐入口

如果你在 Obsidian 中打开这个库，建议按下面顺序进入：

1. [00_NAV/欢迎.md](00_NAV/欢迎.md)
2. [00_NAV/全库总导航.md](00_NAV/全库总导航.md)
3. [01_INDEX/索引总入口.md](01_INDEX/索引总入口.md)
4. 再进入四条主线之一

- [01_INDEX/认知线总纲.md](01_INDEX/认知线总纲.md)

## 维护原则

- 新书先写主笔记，再补行动页
- 能复用的内容尽量沉淀到概念卡
- 新笔记尽量接回总纲或索引
- 历史线尽量按“帝系、权力结构、制度代价、正史回查”统一标准推进

## 一句话

这套库的目标，不是堆积读书摘录，而是把阅读慢慢变成一张能长期复用的知识地图。
