# reading

这是一个基于 Obsidian 构建的个人阅读笔记库。

仓库里不只是单本书的摘录，而是按以下结构逐步沉淀：

- 书籍主笔记：每本书一篇完整读书笔记
- 行动清单：把感悟转成可执行提醒
- 概念卡片：把重要概念拆成可复用的原子笔记
- 跨书索引：把多本书按共同主题重新连接

## 推荐入口

如果你在 Obsidian 中打开这个仓库，建议按下面顺序进入：

1. `欢迎.md`
2. `认知类阅读索引.md`
3. `跨书主题索引.md`

## 使用方式

### 1. 看单本书

先读某本书的主笔记，再看它对应的“行动清单与金句摘录”。

### 2. 看某个主题

直接从 `跨书主题索引.md` 进入，比如：

- 注意力、心性与内在修炼
- 复杂问题与系统结构
- 成长、积累与长期主义
- 创造力、探索与优化
- 决策、杠杆与关键行动

### 3. 持续扩展

以后每读一本新书，都可以继续沿用这套结构：

- 新建一篇主笔记
- 新建一篇行动清单
- 把可复用内容并入已有概念卡片
- 必要时补新的母题卡片
