# 清朝帝系表

## 帝系主线

太祖努尔哈赤 -> 太宗皇太极 -> 世祖顺治 -> 圣祖康熙 -> 世宗雍正 -> 高宗乾隆 -> 仁宗嘉庆 -> 宣宗道光 -> 文宗咸丰 -> 穆宗同治 -> 德宗光绪 -> 宣统帝溥仪

## 最值得看的几段

- 入关与一统：顺治、康熙
- 高峰与定型：雍正、乾隆
- 晚清困局：道光以后外患内乱并发
- 终局：慈禧、光绪、宣统与帝制收束

## 一句话

清朝最值得看的，是一个高度成熟的晚期帝国如何在全球冲击与内部失衡中被迫走向帝制终结。
